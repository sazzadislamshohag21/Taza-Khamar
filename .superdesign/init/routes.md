# Routes

## Current route

- `/` — `index.html` — single-page farm-to-fridge homepage with anchored sections for Shop, Seasonal, Farmers, Finder, Why Sazzad, How it works, Stories, Journal, Newsletter, and footer.

## Requested new route

- `/shop.html` — standalone Shop All page reusing the homepage shell with location prompt, category rail, filters, searchable product grid, and basket summary.

## Routing approach

There is no router or framework. Navigation uses normal HTML anchors and static documents. The Shop All CTA should link to `shop.html`; the Shop All page should link back to `index.html` sections where appropriate.
