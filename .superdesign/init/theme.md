Typography is `Bricolage Grotesque` for display headings and `DM Sans` for body UI; Bangla uses `Noto Sans Bengali`. Main display headings use `clamp(42px, 6.3vw, 96px)`. Cards use 1px ink borders, 2px corners, and hard offset shadows. Breakpoints and responsive rules are in `styles.css`.

## Raw source

The complete theme and component CSS is in `styles.css` (589 lines). The complete behavior source is in `script.js` (318 lines). This repository does not use Tailwind, CSS modules, or a theme provider.
