# 403 Error Page

## Business Context
- **Type/Industry:** E-commerce / web platform error page
- **What they do:** Communicate access restriction to users attempting to reach forbidden content
- **Target audience:** Site visitors encountering permission barriers
- **Page goal:** Acknowledge error state & redirect user intent

# Page Layout & Structure

### Hero
Full-height viewport, centered composition. Light cyan background. Decorative geometric shapes scattered asymmetrically across upper half: outlined circles (3), outlined triangles (3), outlined lines (1 curved, 1 straight), inverted triangle outline (top right). Central illustration: monitor frame + padlock icon + dotted circle halo (cyan stroke). H1 "403 - Forbidden" positioned below illustration in cyan text. Body text "Access to this page is forbidden." in cyan, immediately below h1. All text center-aligned. Clouds shape (white silhouette) anchors bottom edge, spanning full width with organic undulating edge.

### Page Structure
- **Purpose:** Communicate error state with visual hierarchy and contextual direction.
- **Layout:** Single centered column; no navigation, no header, no footer. Entire composition = hero. Decorative elements (shapes, illustration, clouds) provide visual interest without navigation intent.

**Notable patterns:** Asymmetrical scatter of geometric decorations; no repeating sections; single-use cloud footer shape; monochrome cyan text on light cyan background with high contrast through outlined icon.
